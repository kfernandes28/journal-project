# Journal Project -- Iteration Log

## Milestone 2: Search & Discovery

---

## v2.1 -- Journal search

**Goal:** Make it possible to quickly locate specific thoughts without manually scrolling through years of entries.

**What changed**
- Added a live search bar to the dashboard.
- Search filters reflections within the currently selected year.
- Results update instantly as the user types.

**Key learning**

A journal becomes significantly more useful once it is searchable. Rather than remembering *when* something was written, the user can simply remember *what* it was about.

---

## v2.2 -- Search feedback

**Goal:** Provide clear feedback about the current search results.

**What changed**
- Added a search result summary.
- Displays the number of matching reflections for the selected year.
- Entry and word counts now update dynamically based on the filtered results.

**Key learning**

Search feels more intentional when the dashboard clearly communicates what is being displayed, rather than leaving the user to infer it.

---

## v2.3 -- Search highlighting

**Goal:** Improve readability when reviewing search results.

**What changed**
- Added subtle highlighting for matching search terms.
- Preserved the existing journal aesthetic using muted colours rather than intrusive browser-style highlighting.

**Key learning**

The goal of search is not simply finding the correct reflection—it is helping the eye immediately locate *why* that reflection matched while maintaining an enjoyable reading experience.

---

## Current state (Milestone 2 complete)

- Beautiful journal archive
- Year filtering
- Live search
- Dynamic result summary
- Dynamic entry and word counts
- Highlighted search matches
- Static HTML dashboard with no external dependencies

---

## Explicit non-goals

- No AI tagging
- No semantic search
- No embeddings or vector databases
- No sentiment analysis
- No automatic summaries
- No commitment tracking

Milestone 2 focused on making the journal practical to navigate. Before introducing AI, the priority was ensuring reflections could be found quickly and naturally using a fast, lightweight search experience.
